# NAME: JANDA HEMANTH

# REG NO: 212223030015

## Aim

To reproduce a given reference image using prompts with an AI image-generation tool and improve the generated output through prompt refinement and iteration.

## Objective

- To study the important visual features of a reference image.
- To create a basic prompt describing the image.
- To refine the prompt with additional visual details.
- To generate an image using Gemini.
- To compare the generated image with the reference image.
- To improve the result by modifying the prompt.

---

## Requirements

- Reference Image
- Google Gemini
- Internet Connection
- Computer or Mobile Device

---

## Procedure

### Step 1: Examine the Given Image

<img width="1408" height="768" alt="00" src="https://github.com/user-attachments/assets/bb9f0768-b6c9-42f9-9b9f-4250418cebea" />

The reference image was carefully examined to identify:

- Main subject
- Background
- Objects
- Colors
- Lighting
- Composition
- Pose and position
- Camera angle
- Textures
- Image style

### Step 2: Write the Basic Prompt

A simple prompt was created by describing the main subject and important elements of the reference image.

### Step 3: Refine the Prompt

The basic prompt was improved by adding details such as:

- Exact colors
- Background details
- Lighting conditions
- Subject position
- Camera perspective
- Clothing and appearance
- Shadows
- Texture
- Realistic details

### Step 4: Generate the Image Using Gemini

The refined prompt was entered into Google Gemini's image-generation feature to generate an image similar to the reference image.

### Step 5: Compare the Images

The generated image was compared with the original reference image. Differences in the subject, background, colors, lighting, composition, and other details were identified.

### Step 6: Iterate and Adjust

The prompt was modified based on the differences observed. The improved prompt was entered into Gemini again to generate a better result.

### Step 7: Save the Final Output

The final generated image was saved and documented along with the prompts and observations.

---

# Prompts Used
Generate a highly accurate recreation of the provided reference image.

First identify all important visual elements in the reference image, including the subject, pose, facial expression, clothing, background, objects, colors, lighting, shadows, camera angle, perspective, composition, depth, and textures.

Recreate these elements in the same relative positions and proportions.

Use realistic photography, natural lighting, accurate shadows, detailed textures, sharp focus, and high resolution.

Do not introduce new objects, colors, poses, or backgrounds that are not present in the reference image.

The final output should have the closest possible visual similarity to the reference image while maintaining a natural and realistic appearance.
